# Contributing

Open an issue describing the problem, expected behavior, platform and steps to reproduce. Use fictional records and remove private details from screenshots or exports.

For a change, keep the samples independently runnable and dependency-light. Explain the user-visible behavior and how you checked it. Run `npm run build`, `npm test` and, for mobile changes, `npm run test:mobile` plus an Xcode simulator build. Commit generated `docs/` changes with their sources. Preserve labels, keyboard access, validation and local-only boundaries.

Do not submit credentials, private customer material, signed installers or real payment integrations. Contributions are offered under the repository's MIT license.
