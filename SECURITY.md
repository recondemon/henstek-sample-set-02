# Security

These samples are for fictional local demonstrations and template exploration. They are not hosted multi-user business systems. Do not place secrets or sensitive records in the demos or exported JSON.

For a vulnerability, use this repository's **Security → Report a vulnerability** option when available, or contact [HensTek support](mailto:support@henstek.dev) with a minimal reproduction and no secrets. Avoid posting exploitable details publicly before coordination. There is no guaranteed response deadline or managed support service for this free repository.

Keep Electron, Node.js and Xcode current. Adding authentication, remote content, file access, customer data or network integrations changes the security requirements and needs a fresh review.
