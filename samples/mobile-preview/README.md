# Side A Pocket browser preview

An interactive browser adaptation of the SwiftUI mobile sample in `../mobile`. It mirrors the primary screens and workflows, not iOS itself. It runs with fictional data held in memory; reload or Reset demo restores the examples. No account, network writes, purchases or reservations are connected. Native file pickers, sharing, imports/exports and OS integrations are available in the native source, not this preview.

Build with `npm run build`, then open `/mobile/` from the sample gallery. The gallery opens it in a phone-sized frame; it also works directly in a browser.
