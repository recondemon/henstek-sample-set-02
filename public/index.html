Working samples, clear limits.

All businesses, people, releases, schedules and prices are fictional. Illustrative imagery represents the sample venue. The apps do not synchronize; website and browser-preview data stays in that browser. Native apps store files locally. No customer accounts, checkout, payment, music playback or real reservations are connected.

Native checks cover iPhone Simulator and Apple silicon macOS. Mobile source is available to run in Xcode; there is no App Store download. Desktop source can be run locally; it is not a signed or notarized consumer release. Production integrations are scoped separately.
